# 门店调拨入库差异SOP

> Nova Retail 虚拟企业演示制度，不代表真实企业承诺。本文面向直营网业务人员，作为现有基础制度的专题补充。

## 目的与适用条件

统一门店调拨入库差异SOP涉及的受理条件、操作边界及异常留痕。受理前核验会员身份、商品类型、订单状态及适用门店；涉及临时活动时同时核验日期范围，不能把相似业务直接套用。

## 业务规则

1. 按实收数量登记差异并通知发出店复核，不按单据数量强行收齐。
2. 到货损坏商品进入待检隔离库位，拍照关联调拨单后交值班经理判定。
3. 多到商品单独隔离，核清来源并补齐审核单据后才转可售。
4. 调拨收货经办人不能同时作为该笔差异的最终审批人。

## 执行与复核

1. 在原业务单据中核对适用条件和凭证，向顾客说明本主题下可确认的规则。
2. 按上述条款办理，保留订单或设备标识、处理时间及必要的脱敏凭证。由当班责任人复核处理结果。
3. 涉及关联主题时，查阅下列文档后分别执行，不将本文件视为全部流程的授权。

## 异常及升级

系统状态不明、证据不完整或不同文件口径不一致时，登记原始现象并转值班经理或业务支持。不凭相似品名、历史截图或个人经验扩展授权。本文不提供实时账户余额、实时库存或个人排班数据。
