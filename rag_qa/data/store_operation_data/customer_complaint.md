# 门店客诉接待与升级

> 演示声明：本文档是 Nova Retail 虚构业务场景的演示知识，不代表任何真实企业的制度、优惠或承诺。

- 文档编号：NR-STORE_OPERATION-07
- 知识类别：门店运营
- 适用对象：Nova Retail 演示门店员工

## 目的

为一线员工提供统一的倾听、记录、解决和升级方法。

## 核心规则

1. 先确认顾客安全和核心诉求，不争辩、不推责，不承诺超出授权的赔偿。
2. 值班经理可在系统授权范围内处理；涉及人身安全、食品安全、媒体、隐私或高额损失立即升级。
3. 所有升级事件都要记录时间、地点、订单、人员和已采取措施。

## 操作步骤

1. 倾听并复述诉求，确认事实。
2. 核验订单和适用政策，提出授权内方案。
3. 无法解决时说明升级路径和回访方式。
4. 在客诉系统完整记录。

## 例外与升级

- 不得在公开区域讨论顾客隐私。
- 威胁或暴力风险优先报警和疏散，不以完成服务流程为前提。

如现场情况无法由上述规则覆盖，停止作出确定性承诺，保留订单、设备错误码或商品批次等必要信息，并联系值班经理或对应业务支持。
