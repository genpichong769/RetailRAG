# 门店盘点差异处理

> 演示声明：本文档是 Nova Retail 虚构业务场景的演示知识，不代表任何真实企业的制度、优惠或承诺。

- 文档编号：NR-STORE_OPERATION-06
- 知识类别：门店运营
- 适用对象：Nova Retail 演示门店员工

## 目的

规定库存差异的复盘、原因分类和上报门槛。

## 核心规则

1. 差异先复盘，再检查收货、调拨、销售、退货、报损和在途单据。
2. 单 SKU 差异价值超过 200 元或单次总差异超过 1000 元时升级区域运营复核。
3. 原因分为流程未完成、计数错误、破损报损、疑似损失和系统异常，不得使用笼统备注。

## 操作步骤

1. 锁定相关库存，避免继续移动。
2. 由不同人员完成二次计数。
3. 核对全链路单据并上传证据。
4. 按门槛提交值班经理或区域运营审批。

## 例外与升级

- 疑似盗损、串码或批量系统问题直接按事件上报。
- 未经审批不得手工平账。
