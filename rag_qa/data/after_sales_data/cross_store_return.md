# 跨店退货受理补充规定

> Nova Retail 虚拟企业演示制度，不代表真实企业承诺。本文面向直营网业务人员，作为现有基础制度的专题补充。

## 目的与适用条件

统一跨店退货受理补充规定涉及的受理条件、操作边界及异常留痕。受理前核验会员身份、商品类型、订单状态及适用门店；涉及临时活动时同时核验日期范围，不能把相似业务直接套用。

## 业务规则

1. 同一直营网内、系统支持售后联查的门店可受理跨店退货，加盟店不纳入此范围。
2. 跨店退货期限仍从原购买日计算，不因换店受理重新起算。
3. 接待店查不到原单时登记工单转原店核查，不能先付现金。
4. 跨店退货商品先进入接待店售后待检库位，检验通过再按调拨流程归库。
5. 接待店只能确认本店可售库存，不能承诺原店或其他门店库存。

## 执行与复核

1. 在原业务单据中核对适用条件和凭证，向顾客说明本主题下可确认的规则。
2. 按上述条款办理，保留订单或设备标识、处理时间及必要的脱敏凭证。由当班责任人复核处理结果。
3. 涉及关联主题时，查阅下列文档后分别执行，不将本文件视为全部流程的授权。

## 异常及升级

系统状态不明、证据不完整或不同文件口径不一致时，登记原始现象并转值班经理或业务支持。不凭相似品名、历史截图或个人经验扩展授权。本文不提供实时账户余额、实时库存或个人排班数据。
